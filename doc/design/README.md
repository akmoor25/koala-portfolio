## 1. ペルソナと方針

ペルソナは、旅を計画するときのわくわく、実際に旅をしているときのどきどき、偶然の出会い、アクシデントを含む刺激、そして快適さを楽しむ人です。主色（`0xff13b1f2`）とアクセント（`0xFFFFEB3B`）は変えず、次のように表現します。

| ペルソナ             | デザインでの表現                       |
| -------------------- | -------------------------------------- |
| わくわく（計画）     | 空色と黄色、丸い角、黄色のステッカー   |
| どきどき（旅の最中） | 珊瑚色の「いま」、押すと縮むボタン     |
| 偶然の出会い         | 黄色の「つぎ」                         |
| アクシデント         | 深い赤の危険、薄い黄色の注意書き       |
| 快適さ               | 十分なコントラストと、押しやすい大きさ |

- 角の丸みは、ボタンが 14、カードが 16 です。主役の操作（作る、始める、参加する）は、インクの縁付きの黄色のステッカーにします。
- ボタンは、押すと 0.97 倍に縮み、離すと戻ります（90ms の短い動き）。
- 「つぎ」の黄色は、出会いの合図です。
- 危険（削除、退出、停止）の赤は、黄色や珊瑚と混ざらない深い赤にします。
- 文字は 4.5:1 以上、押せる大きさは 48dp 以上です。動きは、OS の「アニメーションを減らす」に従います。

## 2. 色

色は、`KoalaColors`（[koala_colors.dart](../../lib/theme/koala_colors.dart)）にまとめ、`Theme.of(context).koala` で取り出します。明暗ごとに値を持ちます。

### 2.1 主色の上の文字

現状の問題は、主色 `13B1F2` の上の白い文字が 2.44:1 で、基準（小さい文字 4.5:1、大きい文字 3:1。[WCAG 2.1 SC 1.4.3](https://www.w3.org/TR/WCAG21/#contrast-minimum)）を満たさないことでした。この問題は、承知のうえで、割り切りとしました。主色の上の文字とアイコンは、旧サービス「行程さん」のデザインを踏襲して、白のままにします（読みやすさを少し犠牲にします）。

試して、やめた案：

- インク（`042436`）の文字（6.56:1）：基準は満たしますが、見た目が好みに合いませんでした。
- 白い文字をインクで縁取る（`Text` と `Icon` の `shadows` に、影を円周の 16 方向に置く方式）：見た目がよくなく、影の重ね描きで描画が重くなり、画面がカクつきました。

白い文字の読みやすさを上げるときは、文字を太く、大きくする方向で検討します（描画の負荷が増えない）。主色そのものは変えていません。

### 2.3 コントラスト比（実測）

| 組み合わせ        |    比 | 使い道                                         |
| ----------------- | ----: | ---------------------------------------------- |
| 白 / 主色         |  2.44 | [主色の上の文字](#21-主色の上の文字) の例外    |
| インク / 主色     |  6.56 | 使わない（試して、見た目の理由でやめた）       |
| インク / 黄色     | 13.12 | 黄色の上の文字                                 |
| 黄色 / 主色       |  2.00 | 装飾だけ（文字には使わない）                   |
| 黄色 / 白         |  1.22 | 使わない。白い地では、インクの縁付きの面にする |
| 黄色 / ダークの地 | 約 14 | ダークでは、線やリングに使える                 |
| 深い青 / 白       |  6.01 | 白い地の、文字、縁、リング                     |

検査する組み合わせと基準は [6. 検査](#6-検査) にまとめています。主色の上の白は、[2.1](#21-主色の上の文字) の明示的な例外であり、すべての色の組み合わせが基準を満たすわけではありません。

### 2.4 ダークの考え方

ダークでは、広い面（アプリバー、吹き出し）を濃い主色（`0F7CAB`）にして、白い文字を載せます。操作の面（ボタン）は、地に映える明るい主色（`13B1F2`）に、白い文字です。黄色は、ダークの地の上で 14:1 あるので、縁なしで使えます。

## 3. 状態

すべてのボタンに、同じ状態の仕様があります（[button_styles.dart](../../lib/theme/button_styles.dart)）。

| 状態       | 主役、黄色、危険（塗り）                                                         | 副（枠）、文字                   |
| ---------- | -------------------------------------------------------------------------------- | -------------------------------- |
| ノーマル   | 種類ごとの面と文字。影なし                                                       | 枠は深い青の 1.5dp、文字は深い青 |
| ホバー     | 文字の色を 8% 重ねる（主色の面は、白では押した感じが出ないので、濃い紺を重ねる） | 同左                             |
| フォーカス | 文字の色を 10% 重ね、ボタンの外側に 3dp のリング（間隔 2dp）                     | 同左                             |
| 押している | 文字の色を 14% 重ね、0.97 倍に縮む                                               | 同左                             |
| 無効       | 面は地の文字色の 12%、文字は 38%。波紋なし                                       | 枠は 12%、文字は 38%             |
| 処理中     | 色はそのまま。アイコンがスピナーに変わる。押せない                               | 同左                             |

- 押せる最小の大きさは、高さ 48dp（`MaterialTapTargetSize.padded`）。
- 縮む動きは、OS の「アニメーションを減らす」が有効なときは、止まります（色の変化だけ）。
- フォーカスのリングは、面の外に描くので、面の色と同化しません。

## 4. コンポーネント

| 名前                                    | 役割                                 | 場所                    |
| --------------------------------------- | ------------------------------------ | ----------------------- |
| `AppButton`                             | ボタン                               | app_button.dart         |
| `AppIconButton`                         | アイコンのボタン（ツールチップ必須） | 同上                    |
| `PressableScale`                        | 押している間の縮み                   | pressable_scale.dart    |
| `AppBadge`                              | 小さなラベル                         | app_badge.dart          |
| `NoticeBanner`                          | 注意書きの帯                         | notice_banner.dart      |
| `AppDialogActions`                      | ダイアログの「取り消す」と「決める」 | app_dialog_actions.dart |
| `AppSpace`、`AppInsets`、`VGap`、`HGap` | 余白の段階                           | spacing.dart            |
| `ReadableWidth`                         | 広い画面での幅の上限                 | readable_width.dart     |

- `AppButton` の種類は、`primary`（主色）、`accent`（黄色）、`secondary`（枠）、`text`（文字）、`danger`（深い赤）、`dangerText`（文字だけの危険）です。`icon`、`busy`、`expand` を指定できます。
- `AppIconButton` の種類は、`standard`、`filled`、`tonal` です。
- `PressableScale` は、ボタンとカードで共有します。
- `AppBadge` の種類は、`now`（珊瑚）、`next`（黄色）、`info`、`shared`、`warning` です。`NoticeBanner` の種類は、`info`、`warning`、`danger` です。
- `AppDialogActions` は、取り消すを文字のボタン、決めるを塗りのボタンにした組です。
- 余白の段階は、`xsmall` 4、`small` 8、`medium` 16、`large` 24、`xlarge` 32 です。間隔は `const VGap.medium()`、四方の余白は `AppInsets.medium`、向きごとの余白は `EdgeInsets.only(left: AppSpace.small)` のように書きます。
- `ReadableWidth` は、幅が広い画面（タブレットの横）で内容を中央に寄せ、幅を `AppWidth.form`（560dp）か `AppWidth.reading`（720dp）までにします。狭い画面では何もしません。

余白は、この段階から選びます。段階にない値（3、6、12 など）は、バッジや年表の位置合わせなど、部品の中の細かい調整にだけ使います。

幅の上限は、起動、共同編集の設定、参加（560dp）と、旅程、ノート（720dp）に付けています。ダイアログ（「このアプリについて」など）も、部品のテーマで 560dp までです。

`ReadableWidth` は、スクロールの内側に置きます。旅程のように、リストを内側に置けないときは、`ReadableWidth.padding(幅)` が返す左右の余白を、リストの `padding` に渡します（`ScrollablePositionedList` など）。どちらも、余白の部分で指をスクロールできます。ノートは、文書の枠（罫線で囲った入力欄）が中央に並ぶ形で、枠の外は、スクロールしません。しおり一覧は、画面の幅に合わせて列の数を変えるため、上限は付けません。

部品ごとのテーマ（[component_themes.dart](../../lib/theme/component_themes.dart)）は、生の Material のボタン、入力欄、カード、ダイアログ、リスト、スナックバーなどにも、同じ見た目を与えます。入力欄は、薄い空色の塗りと、角の丸い枠で、フォーカスすると枠が 2.5dp の深い青になります。

### 適用先

| 画面                     | 使っているもの                                          |
| ------------------------ | ------------------------------------------------------- |
| 起動                     | `accent`、`NoticeBanner.warning`                        |
| 一覧                     | `AppIconButton`、`accent`、押すと縮むカード、`AppBadge` |
| 操作メニューとダイアログ | `AppDialogActions`、`AppButton`                         |
| 旅程                     | `AppBadge`、`AppIconButton`、黄色の FAB                 |
| 共同編集、参加           | `accent`、`secondary`、`danger`、`NoticeBanner.danger`  |
| ノート                   | 他の人が編集中の帯（薄い黄色）                          |

- 起動：「始める」は `accent`、ポートフォリオの注意は `NoticeBanner.warning` です。
- 一覧：アプリバーは `AppIconButton`、空の状態の「サンプルを追加」は `accent` です。しおりのカードは押すと縮み、共同編集のバッジは薄い空色の丸です。
- 操作メニューとダイアログ：危険な操作の `AppButton` は深い赤です。
- 旅程：「いま」「つぎ」は `AppBadge` の色、都市名は `AppBadge.info`、備考の吹き出しは主色に白い文字です。編集と追加は `AppIconButton`、ノートへは黄色の FAB です。

## 5. 使ってはいけない組み合わせ

- 主色の上の白い文字の例外と、影による縁取りを使わない理由は [2.1](#21-主色の上の文字) を参照。例外を小さな補足の文字に広げない。
- 白い地の上に、黄色の文字や線を置かない（1.22:1）。黄色は、面にして、インクの縁を付ける。
- 主色そのものを、白い地の上の小さな文字に使わない（2.44:1）。`brandDeep` を使う。
- `Colors.red`、`Colors.yellow`、`Colors.orange`、`Colors.amber` を直接書かない。トークンを使う。

## 7. 割り切りと今後

- ライトテーマの Drawer のアイコンは、主色（`13B1F2`）にそろえています（白い地で 2.4:1 で、アイコンの基準 3:1 には届きません。ご要望により、ブランドの統一を優先しました）。
- 縦の線と日付の丸は、飾りなので、主色（`13B1F2`）のままです。意味を持つ文字や縁には、`brandDeep` を使います。
- 日付と時刻の選択、時間帯の行は、Material のボタン（文字）のままです。テーマが同じ見た目を与えるので、状態は同じです。
- 表紙の色（利用者が選ぶ色）、リモートカーソルの 8 色（人を見分ける色）、絵文字の壁紙、フォントは変えていません。
- 色の感じ方は、数値だけでは決まりません。実機のライトとダークの画面（CI の端末ごとの画面）を見て、微調整する余地があります。
