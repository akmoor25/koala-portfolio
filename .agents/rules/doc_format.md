# Documentation Format Rule
- なんらかの事実や調査結果を示すときは、可能な限りエビデンス（参照URLなど）を示してください。
- markdown フォーマットにおいて、強調表現（例: **bold**）は使わないでください。
- `.md` ファイルを修正したら、修正した各ファイルを VS Code で開き、`@command:markdowntable.format`（コマンド ID: `markdowntable.format`）を必ず実行して、整形結果を保存してください。コマンドを実行できない環境では、未実行であることを報告してください。
- mermaid フォーマットにおいて、角括弧 `[ ]` の中身はダブルクォート `""` で囲ってください。（例: ["somethig (e.g. foo bar)"]）
